# commit-phrases

Пользователь кладёт в папку (обычно `~/Downloads`, или текущая рабочая директория)
файлы вида `<project>_<duration>.txt`. В каждом — список коммитов за день (по
строке на коммит, иногда с префиксами `fix:`, `upd:`, `import:` и т.п.), а в конце —
инструкция, как построить фразы (обычно: «дай пару фраз что я сегодня сделал из
коммитов на английский»).

## Шаги

1. Найти исходные файлы: все `*.txt` в папке, **кроме** уже готовых `*_message.txt`.
   Если пользователь назвал конкретные файлы/папку — брать только их.
2. Для каждого файла:
   - Отделить строки коммитов от финальной инструкции (инструкция — последний
     абзац на естественном языке после пустой строки).
   - Выполнить инструкцию из файла. Если она стандартная — 2 коротких
     предложения на английском, в прошедшем времени, от первого лица без «I»
     (`Imported ..., updated ...`). Убрать префиксы коммитов (`fix:`, `upd:`),
     исправить опечатки (`packge` → `package`), объединить похожие пункты.
     Ничего не выдумывать сверх того, что есть в коммитах.
   - Записать результат в `<то же имя без .txt>_message.txt` рядом с исходником
     (перезаписать, если уже есть). Только сами фразы, без markdown и кавычек.
3. В ответе показать содержимое каждого `_message.txt` в отдельном блоке кода
   (чтобы было удобно скопировать), с именем файла над блоком.

Исходные файлы не менять и не удалять.
